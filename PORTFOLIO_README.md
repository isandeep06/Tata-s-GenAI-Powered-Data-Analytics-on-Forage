# Data Scientist Portfolio Website

A professional, responsive portfolio website showcasing Sandeep Maurya's work as a Data Scientist, featuring projects from the Tata iQ – GenAI-Powered Data Analytics Virtual Internship.

## 🌐 Live Preview

Simply open `index.html` in any modern web browser to view the portfolio website.

## ✨ Features

### Design & Layout
- **Modern & Professional** - Clean, contemporary design with gradient backgrounds and smooth animations
- **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Navigation** - One-page layout with smooth scrolling between sections
- **Interactive Elements** - Hover effects, fade-in animations, and dynamic navigation highlighting

### Sections

1. **Hero Section**

2. **About Me**

3. **Skills & Expertise**

   - Responsible AI (Fairness, Explainability, Compliance)

4. **Featured Projects**
   - Exploratory Data Analysis (EDA)
   - Predictive Modeling Plan
   - Business Report & Recommendations
   - AI-Powered Collections System Design

5. **Contact**
   - Email, LinkedIn, and GitHub links

## 🎨 Customization

### Colors
The website uses CSS variables for easy color customization. Edit the `:root` section in `styles.css`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --accent-color: #3b82f6;
    /* ... more variables */
}
```

### Content
- **Personal Information**: Edit text content directly in `index.html`
- **Skills**: Modify the skill cards in the Skills section
- **Projects**: Update project descriptions and tags in the Projects section
- **Contact**: Update email and social media links

### Styling
- **Animations**: Adjust animation speeds and effects in `styles.css`
- **Layout**: Modify grid/flexbox properties for different layouts
- **Responsive Breakpoints**: Adjust media queries at 768px and 480px

## 📱 Responsive Design

The website is fully responsive with breakpoints at:
- **Desktop**: 1200px and above (full layout)
- **Tablet**: 768px - 1199px (adjusted grid columns)
- **Mobile**: Below 768px (single column, hamburger menu)

### Mobile Features
- Hamburger menu with smooth animation
- Stacked layout for better mobile viewing
- Touch-friendly button sizes
- Optimized font sizes for mobile screens

## 🚀 Deployment Options

### GitHub Pages
1. Go to repository Settings
2. Navigate to Pages section
3. Select branch and root folder
4. Save and wait for deployment

### Netlify
1. Drag and drop the folder to Netlify
2. Automatic deployment

### Vercel
1. Import repository
2. Automatic build and deployment

### Traditional Hosting
- Upload all three files (index.html, styles.css, script.js) to your web hosting
- Ensure files are in the same directory
- Access via your domain

## 🔧 Local Development

1. Clone or download the repository
2. Open `index.html` in your browser
3. Or use a local server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Then open http://localhost:8000 in your browser
   ```
